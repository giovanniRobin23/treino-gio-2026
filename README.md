# Treino Gio — PWA de 4 semanas

Aplicativo instalável para acompanhar o plano de treino em casa com pesos e spinning.

## Recursos
- Calendário semanal com seleção de semana e dia.
- Exercícios, séries/repetições e links de busca de demonstrações no YouTube.
- Checklists de exercícios e sessões concluídas.
- Timer de descanso de 30, 60 ou 90 segundos.
- Progresso salvo localmente no dispositivo.
- Manifest e service worker para instalação e uso offline após a primeira visita.

## Publicar com GitHub Pages
1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)** e salve.
4. Aguarde o GitHub publicar o site. A URL normalmente será `https://giovannirobin23.github.io/treino-gio-2026/`.

## Instalar no Android
Abra a URL publicada no Chrome e use o menu do navegador para **Instalar app** ou **Adicionar à tela inicial**.

## Observações
- Os links do YouTube abrem pesquisas de demonstrações, não vídeos específicos.
- Os dados são salvos no armazenamento local do navegador; não há sincronização entre dispositivos.
- O conteúdo é um guia geral de treino. Adapte os exercícios à sua condição e interrompa a atividade se houver dor aguda, tontura ou mal-estar.
